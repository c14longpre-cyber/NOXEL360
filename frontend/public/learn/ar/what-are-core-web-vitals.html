في جملة واحدة: Core Web Vitals هي ثلاثة مقاييس محددة يستخدمها Google لقياس تجربة المستخدم الفعلية على صفحة الويب: سرعة التحميل والتفاعل والاستقرار البصري.

قدم Google Core Web Vitals لتوحيد كيفية قياس تجربة الصفحة، والانتقال من مفاهيم غامضة مثل "يشعر بالسرعة" إلى ثلاثة مقاييس ملموسة وقابلة للقياس.

مقاييس Core Web Vitals الثلاثة

LCP (Largest Contentful Paint) — مدى سرعة ظهور المحتوى الرئيسي. INP (Interaction to Next Paint) — مدى سرعة استجابة الصفحة لإدخال المستخدم. CLS (Cumulative Layout Shift) — مقدار تحرك العناصر المرئية بشكل غير متوقع أثناء التحميل.

💡 هل تعلم؟

تعتمد عتبات Core Web Vitals على بيانات المستخدم الفعلية التي تم جمعها عبر الويب، وليست أهدافًا عشوائية — قام Google بمعايرتها مقابل ما يرتبط فعليًا بتجربة جيدة حقًا.

كيف يبدو 'الجيد'

يحدد Google عتبات محددة لكل مقياس — بشكل عام، يعتبر LCP أقل من 2.5 ثانية، وINP أقل من 200 ميلي ثانية، وCLS أقل من 0.1 جيدًا، بناءً على بيانات المستخدم الفعلية.

كيفية التحقق من Core Web Vitals الخاصة بك

يعرض تقرير Core Web Vitals في Google Search Console وPageSpeed Insights كلاهما هذه المقاييس للصفحات الفعلية، بناءً على بيانات الزوار الفعلية عند توفرها.

الأسئلة الشائعة

هل تعتبر Core Web Vitals عامل ترتيب مباشر في Google؟

نعم، أكد Google أنها جزء من إشارات تجربة الصفحة الأوسع، على الرغم من أن ملاءمة المحتوى لا تزال تحظى بوزن أكبر بشكل عام.

ماذا يعني LCP؟

Largest Contentful Paint — يقيس مدى سرعة ظهور الجزء الرئيسي الأكبر من المحتوى للزائر.

ما الذي حل محل FID (First Input Delay) كأحد Core Web Vitals؟

حل INP (Interaction to Next Paint) محل FID في عام 2024، مما يوفر قياسًا أكثر شمولاً لاستجابة الصفحة.

ما الذي يسبب درجة CLS ضعيفة؟

عناصر مثل الصور أو الإعلانات التي يتم تحميلها دون مساحة محجوزة، مما يتسبب في تحول موضع المحتوى المحيط بشكل غير متوقع أثناء تحميل الصفحة.

هل يمكن أن تختلف Core Web Vitals بين الهاتف المحمول وسطح المكتب؟

نعم، غالبًا بشكل كبير — يقوم Google بالإبلاغ عن هذه المقاييس وتقييمها بشكل منفصل لتجارب الهاتف المحمول وسطح المكتب.

هل يجب أن تكون جميع Core Web Vitals الثلاثة 'جيدة' للحصول على ترتيب جيد؟

ليس مطلوبًا بشكل صارم، ولكن تحقيق جميع العتبات الثلاث يرتبط بإشارة تجربة صفحة أفضل بشكل عام.

كم مرة يحدّث Google عتبات أو مقاييس Core Web Vitals؟

من حين لآخر — كما رأينا في الانتقال من FID إلى INP، يقوم Google بتحسين هذه المقاييس بشكل دوري بناءً على معايير الويب المتطورة والبيانات.

النقاط الرئيسية

  • تقيس Core Web Vitals سرعة التحميل والتفاعل والاستقرار البصري.
  • LCP وINP وCLS هي المقاييس الثلاثة المحددة المعنية.
  • أكد Google أنها جزء من إشارات تجربة الصفحة الأوسع للترتيب.
  • العتبات مبنية على بيانات المستخدم الفعلية، وليست أهدافًا عشوائية.
  • يقوم كل من Search Console وPageSpeed Insights بالإبلاغ عن هذه المقاييس للصفحات الفعلية.
