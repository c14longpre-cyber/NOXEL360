Que sont les Core Web Vitals ? Une explication simple

En une phrase : Les Core Web Vitals sont trois métriques spécifiques que Google utilise pour mesurer l'expérience utilisateur réelle sur une page web : la vitesse de chargement, l'interactivité et la stabilité visuelle.

Google a introduit les Core Web Vitals pour standardiser la façon dont l'expérience de page est mesurée, allant au-delà des notions vagues de « rapide » vers trois métriques concrètes et mesurables.

Les trois Core Web Vitals

LCP (Largest Contentful Paint) — à quelle vitesse le contenu principal devient visible. INP (Interaction to Next Paint) — à quelle vitesse la page répond aux interactions de l'utilisateur. CLS (Cumulative Layout Shift) — à quel point les éléments visuels se déplacent de façon inattendue pendant le chargement.

📚 Sources officielles
  • Google — Core Web Vitals · la documentation officielle des Core Web Vitals
💡 Le saviez-vous ?

Les seuils des Core Web Vitals sont basés sur des données d'utilisateurs réels collectées sur le web, et non sur des cibles arbitraires — Google les a calibrés en fonction de ce qui correspond réellement à une bonne expérience.

À quoi ressemble un « bon » score

Google définit des seuils spécifiques pour chaque métrique — en général, un LCP inférieur à 2,5 secondes, un INP inférieur à 200 millisecondes et un CLS inférieur à 0,1 sont considérés comme bons, basés sur des données d'utilisateurs réels.

Comment vérifier vos propres Core Web Vitals

Le rapport Core Web Vitals de Google Search Console et PageSpeed Insights affichent tous deux ces métriques pour des pages réelles, basées sur les données réelles des visiteurs lorsqu'elles sont disponibles.

Questions fréquemment posées

Les Core Web Vitals sont-ils un facteur de classement direct de Google ?

Oui, Google a confirmé qu'ils font partie des signaux de classement plus larges liés à l'expérience de page, bien que la pertinence du contenu reste globalement plus fortement pondérée.

Que signifie LCP ?

Largest Contentful Paint — mesure la rapidité avec laquelle le plus grand élément de contenu principal devient visible pour un visiteur.

Qu'est-ce qui a remplacé FID (First Input Delay) comme Core Web Vital ?

INP (Interaction to Next Paint) a remplacé FID en 2024, fournissant une mesure plus complète de la réactivité de la page.

Qu'est-ce qui cause un mauvais score CLS ?

Des éléments comme les images ou les publicités qui se chargent sans espace réservé, provoquant un déplacement inattendu du contenu environnant lors du chargement de la page.

Les Core Web Vitals peuvent-ils différer entre mobile et ordinateur ?

Oui, souvent de manière significative — Google rapporte et évalue ces métriques séparément pour les expériences mobiles et ordinateur.

Les trois Core Web Vitals doivent-ils tous être « bons » pour bien se classer ?

Pas strictement requis, mais atteindre les trois seuils est associé à un meilleur signal global d'expérience de page.

À quelle fréquence Google met-il à jour les seuils ou métriques des Core Web Vitals ?

Occasionnellement — comme on l'a vu avec la transition FID vers INP, Google affine périodiquement ces métriques en fonction de l'évolution des standards web et des données.

Points clés à retenir

  • Les Core Web Vitals mesurent la vitesse de chargement, l'interactivité et la stabilité visuelle.
  • LCP, INP et CLS sont les trois métriques spécifiques concernées.
  • Google a confirmé qu'ils font partie de ses signaux de classement plus larges liés à l'expérience de page.
  • Les seuils sont basés sur des données d'utilisateurs réels, et non sur des cibles arbitraires.
  • Search Console et PageSpeed Insights rapportent tous deux ces métriques pour des pages réelles.
