Qu'est-ce qu'un site web ? Une explication simple

En une phrase : Un site web est une collection de pages liées — stockées sur un serveur quelque part dans le monde — que votre navigateur télécharge et affiche lorsque vous visitez un nom de domaine.

Il est facile de prendre les sites web pour acquis, mais beaucoup de choses se passent dans la fraction de seconde entre la saisie d'une adresse web et l'apparition d'une page. Comprendre les éléments de base permet de saisir plus rapidement tous les autres concepts du web.

De quoi est réellement composé un site web

  • Pages — documents individuels écrits en HTML
  • Style — CSS qui contrôle l'apparence des pages
  • Comportement — JavaScript qui rend les éléments interactifs
  • Ressources — images, polices et autres fichiers référencés
  • Un serveur — un ordinateur, toujours en ligne, qui stocke et envoie tout cela sur demande
💡 Le saviez-vous ?

Le tout premier site web, publié en 1991 par Tim Berners-Lee, est toujours en ligne aujourd'hui à son adresse d'origine et ne ressemble en rien aux sites modernes — uniquement du texte brut et des liens.

Ce qui se passe lorsque vous visitez un site web

  1. Vous tapez un nom de domaine ou cliquez sur un lien.
  2. Votre navigateur recherche vers quel serveur ce domaine pointe (via DNS).
  3. Votre navigateur demande la page à ce serveur.
  4. Le serveur renvoie les fichiers de la page.
  5. Votre navigateur assemble et affiche tout ce que vous voyez.

Tout cela se produit généralement en moins d'une seconde — même à l'autre bout de la planète.

Site web vs Application web

Il n'y a pas de frontière technique stricte, mais une règle pratique utile : un site web concerne principalement la lecture de contenu — un blog, une page d'entreprise. Une application web est un logiciel interactif fonctionnant dans un navigateur — un tableau de bord, un processus de paiement. De nombreux produits modernes mélangent les deux.

Questions fréquemment posées

Quelle est la différence entre un site web et une application web ?

En général, un site web est principalement informatif, tandis qu'une application web est un logiciel interactif fonctionnant dans un navigateur — de nombreux produits mélangent les deux.

Dois-je posséder un domaine pour avoir un site web ?

Non — un site web peut fonctionner sur une adresse IP brute ou un sous-domaine gratuit, mais un domaine personnalisé est standard pour tout ce qui est censé avoir l'air crédible.

Un site web est-il la même chose qu'une page web ?

Non. Une page web est une page unique. Un site web est l'ensemble complet des pages cohabitant sous un seul domaine.

De quoi un site web a-t-il besoin au minimum pour fonctionner ?

Au minimum, un fichier HTML et un serveur pour l'héberger — CSS, JavaScript et pages supplémentaires sont des extras optionnels.

Un site web peut-il fonctionner sans JavaScript ?

Oui, de nombreux sites web sont entièrement fonctionnels avec seulement HTML et CSS. JavaScript ajoute de l'interactivité mais n'est pas strictement requis pour du contenu de base.

Pourquoi certains sites web se chargent-ils plus rapidement que d'autres ?

Les facteurs incluent l'emplacement et la vitesse du serveur, la taille des fichiers, l'utilisation d'un CDN, et l'efficacité du code du site.

Un blog est-il considéré comme un site web ?

Oui — un blog est simplement un site web structuré autour d'articles publiés régulièrement, généralement avec un système de gestion de contenu spécifique derrière lui.

Dois-je savoir coder pour avoir un site web ?

Pas nécessairement. Les créateurs de sites web comme Shopify, WordPress et Squarespace vous permettent d'en créer un sans écrire de code.

Qu'est-ce qui rend un site web « responsive » ?

Des techniques CSS qui adaptent la mise en page aux différentes tailles d'écran, de sorte que le même site fonctionne bien sur les téléphones, tablettes et ordinateurs de bureau.

Combien de pages un site web de petite entreprise typique possède-t-il ?

Souvent 5-10 : accueil, à propos, services, contact et quelques pages complémentaires, bien que cela varie considérablement selon le type d'entreprise.

Points clés à retenir

  • Un site web est un ensemble de pages liées stockées sur un serveur et livrées aux navigateurs sur demande.
  • Les pages, le style, le comportement, les ressources et un serveur sont les éléments de base.
  • Visiter un site déclenche une recherche DNS, une requête et une réponse — le tout en moins d'une seconde.
  • Les sites web ont tendance à être informatifs ; les applications web ont tendance à être des logiciels interactifs.
  • Vous n'avez pas besoin de savoir coder pour créer un site web de base aujourd'hui.
