Core Web Vitals nədir? Sadə izahat

Bir cümlə ilə: Core Web Vitals, Google-un veb səhifədə real istifadəçi təcrübəsini ölçmək üçün istifadə etdiyi üç xüsusi metrikadır: yükləmə sürəti, interaktivlik və vizual sabitlik.

Google, səhifə təcrübəsinin necə ölçüldüyünü standartlaşdırmaq, qeyri-müəyyən "sürətli hiss edilir" anlayışından üç konkret, ölçülə bilən metrikaya keçmək üçün Core Web Vitals-ı təqdim etdi.

Üç Core Web Vital

LCP (Largest Contentful Paint) — əsas məzmunun nə qədər tez görünməsi. INP (Interaction to Next Paint) — səhifənin istifadəçi girişinə nə qədər tez cavab verməsi. CLS (Cumulative Layout Shift) — yükləmə zamanı vizual elementlərin gözlənilmədən nə qədər hərəkət etməsi.

📚 Rəsmi Mənbələr
  • Google — Core Web Vitals · rəsmi Core Web Vitals sənədləri
💡 Bilirdinizmi?

Core Web Vitals hədləri ixtiyari hədəflər deyil, veb üzrə toplanan real istifadəçi məlumatlarına əsaslanır — Google onları həqiqətən yaxşı təcrübə ilə əlaqəli olanlara uyğun kalibrlədi.

'Yaxşı' Nəyə Oxşayır

Google hər metrika üçün xüsusi hədlər müəyyən edir — ümumiyyətlə, 2,5 saniyədən az LCP, 200 millisaniyədən az INP və 0,1-dən az CLS real istifadəçi məlumatlarına əsaslanaraq yaxşı hesab olunur.

Öz Core Web Vitals-larınızı Necə Yoxlamaq olar

Google Search Console-un Core Web Vitals hesabatı və PageSpeed Insights hər ikisi mövcud olduğu yerlərdə faktiki ziyarətçi məlumatlarına əsaslanaraq real səhifələr üçün bu metrikalari göstərir.

Tez-tez Verilən Suallar

Core Web Vitals birbaşa Google reytinq faktorudurmu?

Bəli, Google onların daha geniş səhifə təcrübəsi reytinq siqnallarının bir hissəsi olduğunu təsdiqləyib, baxmayaraq ki, məzmun uyğunluğu ümumi olaraq daha çox çəkiyə malikdir.

LCP nəyi ifadə edir?

Largest Contentful Paint — ən böyük, əsas məzmun hissəsinin ziyarətçiyə nə qədər tez görünməsini ölçür.

Core Web Vital kimi FID (First Input Delay) nəyi əvəz etdi?

INP (Interaction to Next Paint) 2024-cü ildə FID-i əvəz etdi və səhifə cavabdehlik səviyyəsinin daha əhatəli ölçüsünü təqdim etdi.

Zəif CLS balına nə səbəb olur?

Şəkillər və ya reklamlar kimi elementlər ayrılmış yer olmadan yükləndikdə, səhifə yükləndikcə ətraf məzmunun gözlənilmədən mövqeyini dəyişməsinə səbəb olur.

Core Web Vitals mobil və masaüstü arasında fərqlənə bilərmi?

Bəli, çox vaxt əhəmiyyətli dərəcədə — Google bu metrikalari mobil və masaüstü təcrübələri üçün ayrıca hesabat verir və qiymətləndirir.

Yaxşı reytinq əldə etmək üçün üç Core Web Vitalın hamısı 'yaxşı' olmalıdırmı?

Ciddi tələb olunmur, lakin hər üç həddi yerinə yetirmək daha yaxşı ümumi səhifə təcrübəsi siqnalı ilə əlaqələndirilir.

Google Core Web Vitals hədlərini və ya metrikalari nə qədər tez-tez yeniləyir?

Bəzən — FID-dən INP-yə keçiddə göründüyü kimi, Google dəyişən veb standartları və məlumatlara əsasən bu metrikalari dövri olaraq təkmilləşdirir.

Əsas Nəticələr

  • Core Web Vitals yükləmə sürətini, interaktivliyi və vizual sabitliyi ölçür.
  • LCP, INP və CLS cəlb olunan üç xüsusi metrikadır.
  • Google onların daha geniş səhifə təcrübəsi reytinq siqnallarının bir hissəsi olduğunu təsdiqlədi.
  • Hədlər ixtiyari hədəflər deyil, real istifadəçi məlumatlarına əsaslanır.
  • Search Console və PageSpeed Insights hər ikisi real səhifələr üçün bu metrikalari bildirir.
