Bir cümlə ilə: Back-end inkişafı, tətbiqin faktiki işləməsi üçün pərdəarxasında baş verən hər şeyin qurulmasıdır — serverlər, verilənlər bazası və hansı məlumatın göstəriləcəyinə, saxlanılacağına və ya dəyişdiriləcəyinə qərar verən məntiq.

Hesaba daxil olduğunuzda, səbətə bir şey əlavə etdikdə və ya "yadda saxla" düyməsini basdıqda, bunu həyata keçirən kodu heç vaxt görmürsünüz — sadəcə nəticəni görürsünüz. Həmin görünməz təbəqə back-enddir.

Back-End Developerləri Faktiki Olaraq Nə Qururlar

  • Serverlər — sorğuları qəbul edir və cavab qaytarır
  • Verilənlər bazası — məlumatı saxlayır və əldə edir
  • API — front-endin məlumat sorğulamağına və göndərməsinə icazə verən qaydalar
  • Biznes məntiqi — faktiki qərar qəbuletmə
  • Təhlükəsizlik — autentifikasiya, icazələr, məlumatın qorunması

Restoran Analogiyasından Yenidən İstifadə

Əgər front-end yemək zalıdırsa, back-end mətbəxdir. Masa arxasında oturan heç kim mətbəxi birbaşa görmür — ancaq hər yemək tamamilə orada baş verənlərdən asılıdır. Mətbəx pozulduqda, yemək zalı da işləməyi dayandırır.

💡 Bilirdinizmi?

Bir "səbətə əlavə et" kliki onlarla back-end əməliyyatını tetikleyə bilər — anbarda yoxlama, endirimlərin tətbiqi, sessiyanın yenilənməsi, analitikanın qeydə alınması — hamısı saniyənin bir hissəsində.

Ümumi Back-End Texnologiyaları

Back-end kodu bir çox dillərdə yazıla bilər — Node.js, Python, Java, PHP, Ruby və Go geniş istifadə olunur. Verilənlər bazaları adətən iki ailəyə bölünür: SQL (strukturlaşdırılmış, cədvəl əsaslı) və NoSQL (çevik, sənəd əsaslı).

📚 Rəsmi Mənbələr
  • MDN — Server Tərəfi Veb İnkişafı · Mozilla-nın server tərəfi kurrikulum
  • PostgreSQL Sənədləri · geniş istifadə olunan SQL verilənlər bazası
  • Node.js Rəsmi Sənədlər · məşhur back-end runtime

Bu Fərqlilik Biznes Sahibləri üçün Nə üçün Əhəmiyyətlidir

Əgər veb saytınız yavaş işləyirsə, trafik altında sınırsa və ya məlumat itirsə, problem demək olar ki həmişə back-enddədir. "Düymə düzgün görünmür" problemi front-enddir; "sifariş cəmi səhvdir" problemi back-enddir.

Tez-tez Verilən Suallar

Back-end inkişafı üçün hansı proqramlaşdırma dilləri istifadə olunur?

Ümumi seçimlərə performans ehtiyaclarından və komanda təcrübəsindən asılı olaraq JavaScript/Node.js, Python, Java, PHP, Ruby və Go daxildir.

Sadə veb-sayt üçün back-end lazımdırmı?

Təkcə məlumat xarakterli sayt yalnız front-end kodu ilə işləyə bilər. Giriş, ödənişlər və ya saxlanılan məlumat olan hər hansı şey üçün back-end lazımdır.

Back-end server ilə eynidir?

Server kodu işlədən maşındır. Back-end həmin serverdə işləyən faktiki tətbiq məntiq və kodudur.

Verilənlər bazası dəqiq olaraq nədir?

Verilənlər bazası bir çox istifadəçi eyni anda ona daxil olduqda belə, məlumatı etibarlı şəkildə saxlamaq və əldə etmək üçün təşkil edilmiş sistemdir.

Back-end front-end olmadan işləyə bilərmi?

Bəli — bir çox back-endlər heç bir vizual interfeys olmadan mobil tətbiqlər, digər xidmətlər və ya avtomatlaşdırılmış sistemlər tərəfindən istehlak olunan təmiz API təqdim edir.

Back-end məlumatı necə təhlükəsiz saxlayır?

Autentifikasiya, şifrələnmiş əlaqələr, icazə yoxlamaları və verilənlər bazasına toxunmadan əvvəl hər daxil olan sorğunun yoxlanılması vasitəsilə.

Back-end dayansa nə olur?

İstifadəçilər adətən səhvlər görür və ya front-end kodu yaxşı yüklənsə belə, tətbiq tamamilə cavab verməyi dayandırır — onun asılı olduğu heç nə işləmir.

Back-end inkişafı front-enddən daha çətindir?

Heç biri obyektiv olaraq daha çətin deyil — onlar fərqli bacarıq dəstləri tələb edir. Back-end daha çox sistem dizaynı və məlumat modelləşdirməsini əhatə edir.

Back-end işi üçün SQL və NoSQL arasında fərq nədir?

SQL verilənlər bazaları ciddi struktur və əlaqələri tətbiq edir; NoSQL verilənlər bazaları sürətlə dəyişən və ya müxtəlif məlumatlar üçün daha çevikdir.

Back-end developerləri də front-end kod yazırlar?

Bəziləri yazır — bu üst-üstə düşmə full-stack developeri təyin edir — amma çoxları tamamilə back-end sistemlərində ixtisaslaşır.

Əsas Qeydlər

  • Back-end inkişafı, tətbiqin faktiki işləməsini təmin edən görünməz sistemləri qurur.
  • Serverlər, verilənlər bazası, API və biznes məntiq əsas back-end komponentləridir.
  • Ümumi dillərə Node.js, Python, Java, PHP, Ruby və Go daxildir.
  • SQL və NoSQL verilənlər bazaları fərqli məlumat ehtiyaclarına xidmət edir.
  • Əksər funksional səhvlər — yanlış cəmlər, itirilmiş məlumat — back-endə əlaqəlidir.
