Bir cümlə ilə: Front-end proqramlaşdırma istifadəçilərin həqiqətən gördüyü və tıkladığı veb sayt və ya tətbiqin hissəsini qurmağıdır — tərtibat, düymələr, rənglər və onunla qarşılıqlı əlaqə qurduğunuzda cavab verən hər şey.

Hər dəfə veb sayt açdığınızda və mətn, şəkillər və tıkladığınızda cavab verən düymələr yükləyəndə, front-end kodun işini görürsünüz. Əgər back-end proqramlaşdırma mühərrikdirsə, front-end idarə paneli, sükan və sürücünün həqiqətən toxunduğu hər şeydir.

Front-End Tərtibatçılar Həqiqətən Nə Qururlar

  • Səhifə tərtibatı və quruluşu
  • Mətn formatlaması, rənglər, boşluqlar və vizual üslublaşdırma
  • İnteraktiv elementlər — açılan menyular, formalar, düymələr, animasiyalar
  • Səhifənin telefonlarda, planşetlərdə və masaüstü kompüterlərdə düzgün görünməsini təmin etmə
  • İnterfeysi məlumatla birləşdirmə — istifadəçinin adını göstərmə, səbət cəmini yeniləmə
💡 Bilirdinizmi?

Üç əsas front-end texnologiyası — HTML, CSS və JavaScript — hamısı pulsuz, açıq veb standartlarıdır. Heç bir şirkət onlara sahib deyil və hər bir brauzer onları eyni şəkildə dəstəkləmək məcburiyyətindədir.

Üç Əsas Tikinti Bloku

HTML quruluşu təmin edir — başlıqlar, abzaslar, şəkillər, düymələr.

CSS vizual təqdimatı idarə edir — rənglər, şriftlər, boşluqlar, tərtibat.

JavaScript davranış əlavə edir — tıkladığınızda, kaydırdığınızda və ya yazdığınızda nə baş verir.

Müasir front-end işinin əksəriyyəti React, Vue və ya Angular kimi freymvorklar ilə həyata keçirilir ki, bu da hər şeyi sıfırdan yazmadan mürəkkəb interfeyslər qurmağı daha sürətli edir.

Front-End və Back-End, Sadə İfadələrlə

Əgər veb sayt bir restoran olsaydı, front-end yemək zalıdır — müştərinin gördüyü və qarşılıqlı əlaqə qurduğu yer. Back-end mətbəxdir — həqiqi işin baş verdiyi yer, gözdən kənarda. Hər ikisi vacibdir; heç biri digəri olmadan yaxşı işləmir.

Tez-tez Verilən Suallar

Front-end proqramlaşdırmanı öyrənmək çətindir?

Əsaslar — HTML və CSS — başlayanlar üçün əlçatandır. JavaScript freymvorkları ilə mürəkkəb interfeyslər qurmaq mənimsəmək üçün daha çox vaxt tələb edir.

Front-end tərtibatçılar dizayn bilməlidirlər?

Dizayner kimi deyil, amma güclü front-end tərtibatçılar dizayn prinsiplərini dizaynerin işini dəqiq tətbiq edəcək qədər yaxşı başa düşürlər.

Front-end və UI/UX dizayn arasında fərq nədir?

UI/UX dizaynerlər interfeysin necə görünməli və davranmalı olduğuna qərar verirlər. Front-end tərtibatçılar bu qərarları real edən kodu yazırlar.

Veb sayt qurmaq üçün React kimi freymvorka ehtiyacım var?

Xeyr. Sadə HTML, CSS və JavaScript tam veb sayt qura bilər. Freymvorklar interfeys mürəkkəb və interaktiv olduqda faydalı olur.

Front-end proqramlaşdırma veb dizaynla eynidir?

Xeyr. Veb dizayn vizual tərtibat və istifadəçi təcrübəsi qərarlarına fokuslanır. Front-end proqramlaşdırma bu qərarları həyata keçirən kodu yazmaqdır.

Front-end tərtibatçılar back-end olmadan işləyə bilərlər?

Statik məzmun üçün, bəli. Hesablar, saxlanılmış məlumat və ya dinamik məzmun tələb edən hər hansı şey qoşulmaq üçün back-end tələb edir.

İndi ən populyar front-end freymvork hansıdır?

React ən geniş istifadə olunan olaraq qalır, ardınca Vue və Angular gəlir — hər biri güclü ekosistem və aktiv icmalara malikdir.

Mobil tətbiq proqramlaşdırması front-end veb proqramlaşdırması ilə eynidir?

Onlar əlaqəlidir, lakin fərqlidir. Mobil tətbiqlər tez-tez fərqli alətlərdən istifadə edir (Swift, Kotlin və ya React Native kimi), baxmayaraq ki, əsas UI konsepsiyaları üst-üstə düşür.

Front-end proqramlaşdırmada işə hazır olmaq nə qədər vaxt aparır?

Ardıcıl məşqlə, bir çox insan 6-12 ayda junior səviyyəsinə çatır, baxmayaraq ki, bu əvvəlki təcrübə və təhsil intensivliyindən asılı olaraq geniş şəkildə dəyişir.

Front-end tərtibatçılar testlər yazır?

Bəli, getdikcə daha çox. Avtomatlaşdırılmış testlər xüsusilə interfeyslər daha mürəkkəb böyüdükcə istifadəçilər etməzdən əvvəl pozulmuş interfeyslərə yol verir.

Front-end terminlərində responsive dizayn nədir?

Bu, CSS yazmaqla tərtibatın müxtəlif ekran ölçülərinə — telefonlar, planşetlər və masaüstü kompüterlər — tək kod bazasından təmiz uyğunlaşması deməkdir.

Əsas Qeydlər

  • Front-end proqramlaşdırma istifadəçinin birbaşa gördüyü və qarşılıqlı əlaqə qurduğu hər şeyi qurur.
  • HTML, CSS və JavaScript üç əsas tikinti blokudur.
  • Müasir front-end işi adətən mürəkkəbliyi idarə etmək üçün React kimi freymvorklara əsaslanır.
  • Front-end və back-end tamamlayıcıdır — biri görünməzdir, biri deyil.
  • Front-end tərtibatçılar dizayn qərarlarını real, işləyən koda çevirirlər.
