Bir cümlə ilə: Verilənlər bazası, tətbiqlərin lazım olan məlumatları dəqiq, sürətli və etibarlı şəkildə tapa bilməsi üçün verilənlərin saxlanılması, əldə edilməsi və yenilənməsi üçün təşkil edilmiş sistemdir, hətta çoxlu istifadəçilər eyni vaxtda ona daxil olsalar belə.

Hər yaratdığınız hesab, internetdə verdiğiniz hər sifariş, göndərdiyiniz hər mesaj — bunların hamısı hardasa bir verilənlər bazasında yaşayır.

Niyə Sadəcə Cədvəl İstifadə Etməyək?

Cədvəl kiçik, sadə verilənlər üçün yaxşıdır ki, bir nəfər eyni anda redaktə edir. Verilənlər bazaları cədvəlin pis işlədiyi hər şey üçün mövcuddur: çoxlu insanın eyni vaxtda oxuması və yazması, qaydaların tətbiqi, milyonlarla qeydlərin idarə edilməsi, xətalardan təmiz şəkildə bərpa olunma.

💡 Bilirdinizmi?

Bəzi istehsalat verilənlər bazaları saniyədə milyonlarla oxuma və yazma əməliyyatını idarə edir — heç bir cədvəlin heç vaxt yaxınlaşa bilməyəcəyi miqyas, nə qədər böyük olursa olsun.

SQL Verilənlər Bazaları: Strukturlaşdırılmış və Relational

SQL verilənlər bazaları (PostgreSQL, MySQL, SQL Server) verilənləri müəyyən edilmiş sütunlara malik cədvəllərə təşkil edir. "Müştərilər" cədvəli paylaşılan ID vasitəsilə "sifarişlər" cədvəlinə bağlanır, ciddi şəkildə tətbiq olunur. Aydın, sabit əlaqələrə malik verilənlər üçün əla.

NoSQL Verilənlər Bazaları: Çevik və Sənəd Əsaslı

NoSQL verilənlər bazaları (MongoDB, DynamoDB) verilənləri daha çevik şəkildə saxlayır, çox vaxt müstəqil sənədlər kimi. Hər qeydin eyni strukturu paylaşması üçün ciddi tələb yoxdur — sürətlə dəyişən və ya müxtəlif verilənlər üçün yaxşıdır.

Tez-Tez Verilən Suallar

SQL yoxsa NoSQL daha yaxşıdır?

Heç biri universal olaraq daha yaxşı deyil. SQL aydın əlaqələri olan strukturlaşdırılmış verilənlər üçün uyğundur. NoSQL çevik və ya sürətlə dəyişən verilənlər strukturları üçün uyğundur.

Layihə həm SQL, həm də NoSQL istifadə edə bilərmi?

Bəli. Bir çox sistemlər əsas tranzaksiya verilənləri üçün SQL, keşləmə, axtarış və ya yüksək həcmli hadisə qeydiyyatı üçün NoSQL istifadə edir.

Cədvəl verilənlər bazası ilə müqayisədə nədir?

Cədvəl kiçik verilənləri əl ilə saxlamaq üçün sadə, tək fayldan ibarət üsuldur. Verilənlər bazası miqyas, paralel giriş və etibarlı bütövlük üçün qurulub.

Relational verilənlər bazasında 'relational' nə deməkdir?

Bu, cədvəllərin paylaşılan açarlar vasitəsilə bir-birinə bağlı olması deməkdir, beləliklə əlaqəli verilənlər — məsələn, müştəri və onun sifarişləri — bağlantılı və ardıcıl qalır.

Verilənlər bazası eyni vaxtda çoxlu istifadəçini necə idarə edir?

Kilid və tranzaksiyalar kimi mexanizmlər vasitəsilə, bunlar eyni qeydi redaktə edən iki nəfərin səssizcə bir-birinin üzərinə yazmasının qarşısını alır.

Əsas açar nədir?

Cədvəldəki hər qeyd üçün unikal identifikator — məsələn, müştəri ID-si — verilənlər bazasının istənilən yerindən həmin dəqiq qeydə istinad etmək üçün istifadə olunur.

MySQL SQL ilə eynidir?

Xeyr. SQL sorğu dilidir. MySQL, PostgreSQL və SQL Server kimi digərləri ilə yanaşı, SQL istifadə edən xüsusi verilənlər bazası sistemidir.

Verilənlər bazası indeksləşdirmə nədir?

Kitabın arxasındakı indeksə bənzər sürətli axtarış strukturu yaradaraq verilənlərin əldə edilməsini sürətləndirən texnikadır.

Kiçik layihələrə real verilənlər bazası lazımdır?

Tez-tez bəli, birdən çox istifadəçi olduqda və ya etibarlı, strukturlaşdırılmış saxlama ehtiyacı olduqda — hətta kiçik SQLite verilənlər bazası bunun üçün cədvəldən üstündür.

Verilənlər bazası yeniləmə zamanı enerji itirsə nə baş verir?

Yaxşı dizayn edilmiş verilənlər bazaları kəsilmiş yeniləmənin ya tam başa çatmasını, ya da heç başlamasını təmin etmək üçün tranzaksiyalardan istifadə edir, pozulmuş verilənlərin qarşısını alır.

Əsas Nöqtələr

  • Verilənlər bazaları hətta çoxlu paralel istifadəçilərlə belə verilənləri etibarlı şəkildə təşkil edir və əldə edir.
  • SQL verilənlər bazaları ciddi, cədvəl əsaslı struktur tətbiq edir — əlaqəli verilənlər üçün ideal.
  • NoSQL verilənlər bazaları müxtəlif və ya sürətlə dəyişən verilənlər üçün çevik, sənəd əsaslı saxlama təklif edir.
  • Bir çox real sistemlər müxtəlif ehtiyaclar üçün hər iki növdən birləşir.
  • Düzgün seçim verilənlər əlaqələrinizin nə qədər strukturlaşdırılmış və sabit olmasından asılıdır.
