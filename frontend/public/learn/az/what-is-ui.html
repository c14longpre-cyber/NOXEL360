Bir cümlə ilə: UI (İstifadəçi İnterfeysi) kiminsə istifadə etdiyi faktiki vizual və interaktiv səthdir — düymələr, menyular, rənglər, tipoqrafiya və onların birbaşa gördüyü və toxunduğu hər bir ekran elementi.

Əgər UX məhsuldan istifadənin bütün təcrübəsidirsə, UI kiminsə əslində gördüyü və kliklədiyi xüsusi, əlbəəl təbəqədir — vizual və interaktiv dizaynın özü.

UX və UI: Fərqi Yadda Saxlamağın Sadə Yolu

Avtomobil təsəvvür edin. UX onu idarə etməyin bütün təcrübəsidir — necə intuitiv hiss olunduğu, sizi rahat şəkildə hara getməli olduğunuz yerə çatdırıb-çatdırmaması. UI isə göstərici paneli, sükan və düymələrdir — fiziki olaraq qarşılıqlı əlaqədə olduğunuz konkret şeylər.

💡 Bildinizmi?

İnterfeys dizaynı kompüterlərdən tamamilə əvvəl mövcud idi — avtomobil göstərici panelinin və ya təyyarə kokpitinin tərtibatı fiziki idarəetmələrə eyni əsas prinsipləri tətbiq edən UI dizaynının bir formasıdır.

UI Dizaynının Əsas Elementləri

  • Tərtibat — elementlərin ekranda necə düzüldüyü
  • Tipoqrafiya — şrift seçimləri, ölçüləndirmə, oxunaqlılıq
  • Rəng — palet, kontrast, brend ardıcıllığı
  • İnteraktiv vəziyyətlər — düymələrin üzərindən keçdikdə, klikləndikdə və ya deaktiv olduqda necə göründüyü
  • İkonlar və təsvir — mətndən kənarda vizual kommunikasiya
📚 Rəsmi Mənbələr
  • Material Design Təlimatları · Google-un geniş istinad edilən UI dizayn sistemi

'Yaxşı' UI Dizaynını Nə Edir

Yaxşı UI yalnız cilalanmış görünmək haqqında deyil — aydınlıq və ardıcıllıq haqqındadır. Oxşar hərəkətlər oxşar görünməlidir; vacib elementlər fərqlənməlidir; interfeys izah edilməyə ehtiyac duymadan başa düşülməlidir.

Tez-Tez Verilən Suallar

UI yalnız şeyləri gözəl göstərməklə bağlıdırmı?

Tam olaraq yox — yaxşı UI vizual cəlbediciliklə yanaşı, funksiyanı da aydın şəkildə çatdırır (klikə bilənin nə olduğunu, deaktiv olanın nə olduğunu).

Məhsulun əla UI-si, lakin zəif UX-i ola bilərmi?

Bəli — gözəl interfeys, əsas axın və ya məntiq istifadəçinin məqsədinə xidmət etməzsə, yenə də çaşdırıcı və ya istifadəsi əsəbiləşdirici ola bilər.

UI dizaynı üçün hansı alətlər ümumi istifadə olunur?

Figma hazırda ən geniş istifadə olunan alətdir, Sketch və Adobe XD ilə birlikdə interfeyslərin dizaynı və prototipləşdirilməsi üçün istifadə edilir.

UI dizaynı qrafik dizaynla eynidir?

Əlaqəlidir, lakin fərqlidir — qrafik dizayn tez-tez statik vizuallara fokuslanır; UI dizaynı isə xüsusi olaraq interaktiv, funksional interfeysləri əhatə edir.

Dizayn sisteminin UI ilə əlaqəsi nədir?

Dizayn sistemi təkrar istifadə oluna bilən UI komponentləri — düymələr, rənglər, boşluqlar — təmin edir ki, bütün məhsul boyu interfeys ardıcıl olsun.

UI dizaynı platforma konvensiyalarına əməl etməlidirmi?

Ümumiyyətlə bəli — tanış nümunələrə əməl etmək (standart düymə yerləşdirməsi kimi) yeni istifadəçilər üçün öyrənmə əyrisini azaldır.

AI bu gün UI dizaynına kömək edə bilərmi?

Getdikcə daha çox bəli — AI alətləri ilkin tərtibatlar və ya komponentlər yarada bilər, lakin onları real istifadəyə yararlılıq üçün təkmilləşdirmək hələ də insan dizayn mühakiməsindən faydalanır.

Əsas Qeydlər

  • UI kiminsə birbaşa gördüyü və kliklədiyi xüsusi vizual və interaktiv səthdir.
  • Tərtibat, tipoqrafiya, rəng və interaktiv vəziyyətlər əsas UI elementləridir.
  • UX bütün təcrübədir; UI onun daxilində vizual təbəqədir.
  • Yaxşı UI funksiyanı aydın şəkildə çatdırır, yalnız vizual cilalama deyil.
  • Dizayn sistemi bütün məhsul boyu UI elementlərini ardıcıl saxlayır.
