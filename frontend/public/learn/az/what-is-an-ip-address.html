IP Ünvanı Nədir? Sadə Izahat

Bir cümlə ilə: IP ünvanı şəbəkəyə qoşulmuş hər bir cihaza təyin olunan unikal rəqəmsal identifikatordur ki, məlumat dəqiq olaraq hara getməli olduğunu bilsin.

İnternetə qoşulmuş hər cihazın — telefonunuzun, noutbukunuzun və hər vebsaytı yerləşdirən hər serverin — IP ünvanı var. Bu, DNS-in domen adını çevirdiyi əsl təyinat yeridir.

IP Ünvanı Necə Görünür

Tipik IPv4 ünvanı 192.168.1.1 kimi görünür — nöqtələrlə ayrılmış dörd rəqəm, hər biri 0 ilə 255 arasında. Bu, təxminən 4,3 milyard unikal ünvana imkan verir.

💡 Bilirdinizmi?

IPv6 təxminən 340 undesilyona yaxın unikal ünvanı dəstəkləyir — Yerdəki hər qum dənəsinə dəfələrlə unikal ünvan təyin etməyə kifayət edər.

IPv4 və IPv6

İnternetə qoşulmuş cihazlar partladıqca, dünya IPv4 ünvanlarından tükənməyə başladı. IPv6 bunu həll etmək üçün yaradıldı, çox daha böyük sayda ünvana imkan verən daha uzun format istifadə edir. Bu gün hər ikisi yan-yana işləyir.

📚 Rəsmi Mənbələr
  • IANA — IP Ünvan Təyinatı · qlobal IP ünvan təyinatını idarə edən orqan

İctimai və Xüsusi IP Ünvanları

Ev şəbəkənizdəki cihazların hər biri xüsusi IP ünvanı alır, yalnız şəbəkəniz daxilində görünən. Bütün şəbəkəniz internet provayderin təyin etdiyi bir ictimai IP paylaşır ki, bu da internetin qalan hissəsinin gördüyü şeydir.

Tez-tez Verilən Suallar

IP ünvanım mənim dəqiq yerimi göstərirmi?

Adətən provayderlə bağlı ümumi sahə göstərir, dəqiq ünvan yox. Dəqiqlik provayder və məkandan asılı olaraq əhəmiyyətli dərəcədə dəyişir.

Niyə IPv4 ünvanları bitir?

IPv4 təxminən 4,3 milyard unikal ünvana imkan verir — bu gün qoşulmuş cihazların sayı üçün çox azdır, buna görə də IPv6 yaradıldı.

Hər vebsaytın öz IP ünvanı varmı?

Çox vaxt eyni serverdə bir neçə vebsayt tək IP-ni paylaşır, domen adı ilə fərqləndirilir — bu ziyarətçi təcrübəsinə təsir etmir.

IP ünvanım zamanla dəyişə bilərmi?

Bəli, xüsusilə ev internet bağlantıları üçün, provayderlər tez-tez dövri olaraq dəyişən dinamik IP-lər təyin edir.

Statik IP ünvanı nədir?

Dəyişməyən, sabit qalan IP ünvanı, tez-tez stabil, proqnozlaşdırıla bilən ünvana ehtiyacı olan serverlər üçün istifadə olunur.

IP ünvanımı kimisə ilə paylaşmaq təhlükəsizdirmi?

Ümumiyyətlə özü-özlüyündə aşağı risk, baxmayaraq ki, ümumi məkanı göstərə bilər və digər məlumatlarla birlikdə izləməyə töhfə verə bilər.

İki cihaz eyni IP ünvanına malik ola bilərmi?

Eyni şəbəkədə eyni vaxtda yox — bu münaqişəyə səbəb olar. Fərqli, ayrı şəbəkələrdə xüsusi IP-lər təkrarlana bilər.

Əsas Qeydlər

  • İnternetə qoşulmuş hər cihazın unikal IP ünvanı var.
  • IPv4 ünvanları 192.168.1.1 kimi görünür; IPv6 daha çox ünvan üçün daha uzun format istifadə edir.
  • Xüsusi IP-lər ev şəbəkəsi daxilində tətbiq olunur; ictimai IP bütün şəbəkəni internetə təmsil edir.
  • DNS bu rəqəmsal ünvanları dostluq domen adlarına çevirmək üçün xüsusi olaraq mövcuddur.
  • IP ünvanları DNS və ya firewall qaydalarını konfiqurasiya edərkən birbaşa əhəmiyyət kəsb edir.
