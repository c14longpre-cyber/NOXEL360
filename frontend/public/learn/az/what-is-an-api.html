API Nədir? Proqramçı Olmayanlar üçün Praktik Bələdçi

Bir cümlədə: API (Tətbiq Proqramlaşdırma İnterfeysi) iki proqram təminatı parçasının bir-biri ilə danışmasına və məlumat mübadiləsi etməsinə imkan verən qaydalar toplusudur — heç biri digərinin daxili quruluşunu bilməyə ehtiyac duymadan.

Yəqin ki, "API" sözünü məhsul görüşlərində, alət təsvirlərində və ya inkişafçı sənədlərində eşitmisiniz. Onun əslində nə etdiyini başa düşmək üçün kod yazmağa ehtiyac yoxdur — və bir dəfə başa düşdükdən sonra, hər yerdə API-ləri görməyə başlayacaqsınız.

Real Dünya Analoqiyası

API-ni restoran menyusu kimi düşünün. Siz (müştəri) mətbəxin necə işlədiyini, soyuducuda nəyin olduğunu və ya aşpazın necə yemək hazırladığını bilməyə ehtiyac duymursunuz. Sadəcə menyudan bir element seçirsiniz, ofisiant sifarişinizi mətbəxə aparır və yemək geri gəlir.

Menyu API-dir. O, sizə dəqiq olaraq nə istəyə biləcəyinizi, hansı formatda və nə əldə edəcəyinizi deyir — heç bir qarışıq daxili detalları ifşa etmədən.

💡 Bilirdinizmi?

Hər dəfə "Google ilə daxil ol" və ya "Facebook ilə daxil ol" istifadə edərək veb-sayta daxil olduqda, API-dən istifadə edirsiniz. Tətbiqiniz Google-un API-nə kim olduğunuzu təsdiq etməsini xahiş edir, heç vaxt Google parolunuzu görməyərək.

API Çağırışı Necə İşləyir

Hər dəfə bir tətbiq sizə bugünkü hava məlumatını göstərəndə, paketin göndərmə statusunu yoxladıqda və ya kredit kartı ödənişini emal etdikdə, demək olar ki, pərdə arxasında bir API-yə müraciət edir:

  1. Sorğu — Tətbiqiniz xüsusi bir şey xahiş edən strukturlaşdırılmış mesaj göndərir.
  2. Emal — Qəbul edən sistem cavabı axtarır və ya hesablayır.
  3. Cavab — Tətbiqinizin göstərdiyi strukturlaşdırılmış məlumatı, adətən JSON formatında geri göndərir.

Ümumi API Növləri

REST API-ləri bu gün internetdə ən çox yayılmış üslubudur — hər məlumat parçasının öz URL-i var, standart hərəkətlərlə əlçatandır.

GraphQL API-ləri sorğu verən tətbiqə tək bir sorğuda lazım olan sahələri dəqiq olaraq soruşmağa imkan verir.

Webhook-lar istiqaməti çevirir: digər sistem bir şey baş verən anda avtomatik olaraq tətbiqinizə bildiriş göndərir.

API-lər Biznes üçün Niyə Vacibdir

API-lər müasir proqram təminatı ekosistemlərinin hər şirkətin sıfırdan hər şeyi qurması olmadan əlaqə qura bilməsinin səbəbidir:

  • Onlayn mağaza ödəniş prosessorununun API-nə müraciət edərək kredit kartlarını qəbul edə bilər.
  • Marketinq aləti hər platformanın API-si vasitəsilə avtomatik olaraq sosial mediaya paylaşım edə bilər.
  • İnventar və mühasibat sistemləri əl ilə məlumat daxil etmədən sinxronizasiyada qala bilər.

Tez-tez Verilən Suallar

API-dən istifadə etmək üçün kodlaşdırma bilməliyəmmi?

API üzərində qurulmuş alətdən istifadə etmək üçün, xeyr. API-yə birbaşa müraciət edən proqram yaratmaq üçün, bəli — baxmayaraq ki, bir çox no-code alətləri artıq kod yazmadan API-ləri birləşdirməyə imkan verir.

API veb-saytla eyni şeydir?

Xeyr. Veb-sayt insanların brauzerdə oxuması üçün yaradılıb. API proqram təminatının digər proqram təminatı ilə danışması üçün yaradılıb, adətən vizual səhifə əvəzinə strukturlaşdırılmış məlumat mübadiləsi edir.

'REST API' nə deməkdir?

REST bu gün internetdə ən çox yayılmış API dizayn üslubudur. Məlumatları resurslara təşkil edir, hər birinin öz ünvanı var, GET, POST və DELETE kimi standart əməliyyatlarla əlçatandır.

API-dən istifadə pulsuzdur?

Provayderdən asılıdır. Bir çox API məhdud istifadə ilə pulsuz səviyyə təklif edir, sonra həddini aşdıqdan sonra həcmə görə ödəniş tələb edir.

API-lər uğursuz ola və ya işdən çıxa bilər?

Bəli. Provayderin serverləri işdən çıxsa və ya siz sürət həddini aşsanız, sorğular uğursuz ola bilər. Yaxşı qurulmuş proqram təminatı bunu yenidən cəhdlər və ya ehtiyat mesajları ilə idarə edir.

REST GraphQL-dən daha yaxşıdır?

Heç biri universal olaraq daha yaxşı deyil — REST daha sadə və daha geniş dəstəklənir, GraphQL isə xüsusi, yerləşdirilmiş məlumat sorğuları üçün daha səmərəlidir.

API-lər təhlükəsizdir?

API-lər düzgün qurulduqda çox təhlükəsiz ola bilər, autentifikasiya açarları, şifrələmə və icazə nəzarətlərindən istifadə edərək — lakin pis təmin edilmiş API məlumatları ifşa edə bilər.

İki veb-sayt API-lər vasitəsilə əlaqə saxlaya bilər?

Bəli — bir veb-saytın serveri digər veb-saytın API-nə müraciət edərək məlumat çəkir, məsələn, canlı göndərmə tarifləri və ya daxil edilmiş xəritə.

JSON bir API-dir?

Xeyr. JSON məlumat formatıdır. Əksər müasir API-lər göndərdikləri və aldıqları məlumatı formatlaşdırmaq üçün JSON-dan istifadə edirlər, lakin JSON-un özü API deyil.

API xəbərdarlıq etmədən dəyişərsə nə olur?

Bu pozucu dəyişiklikdir və asılı proqram təminatının işləməsini dayandıra bilər. Etibarlı provayderlər öz API-lərini versiyalaşdırır və əvvəlcədən xəbərdarlıq verirlər.

Çatbotlar kimi AI alətləri API-lərdən istifadə edə bilər?

Bəli. Bir çox AI köməkçiləri canlı məlumat əldə etmək və ya hərəkətlər etmək üçün xarici API-lərə müraciət edə bilir — tez-tez alət istifadəsi və ya funksiya çağırışı adlanır.

Shopify kimi məşhur platformaların API-ləri var?

Bəli, əksər böyük platformalar — Shopify, Google, Stripe, Facebook — digər proqram təminatının onlarla inteqrasiya oluna bilməsi üçün ictimai API-lər təklif edirlər.

Əsas Nəticələr

  • API-lər iki proqram təminatı parçasının heç biri digərinin daxili işləməsini bilmədən məlumat mübadiləsinə imkan verir.
  • Sorğular göndərilir, emal edilir və strukturlaşdırılmış məlumat geri gəlir — adətən JSON formatında.
  • REST, GraphQL və webhook-lar ən çox yayılmış üç API üslubudur.
  • Bizneslər hər gün API-lərə etibar edir, tez-tez bunu fərq etmədən.
  • API-ləri başa düşmək iki alətin avtomatik olaraq birləşdirilə biləcəyini qiymətləndirməyə kömək edir.
