Bir cümlədə: Reverse proxy ziyarətçilər və veb saytın həqiqi backend serverləri arasında yerləşən, onların adından sorğuları ötürən və tez-tez keşləmə, təhlükəsizlik və ya yük paylama əlavə edən serverdir.

Reverse proxy faydalı bir dolayı yol təbəqəsi əlavə edir — ziyarətçilər proxy ilə qarşılıqlı əlaqədə olur, heç vaxt arxadakı real backend serverlərlə birbaşa əlaqə qurmazlar.

Reverse Proxy vs Forward Proxy

Forward proxy müştərilərin qarşısında yerləşir və onların şəxsiyyətini qoşulduqları serverlərdən gizlədir. Reverse proxy əksinə edir — o, serverlərin qarşısında yerləşərək onların şəxsiyyətini və təfərrüatlarını ziyarətçilərdən gizlədir.

💡 Bilirdinizmi?

Nginx və Cloudflare kimi məşhur texnologiyalar xüsusi olaraq reverse proxy kimi geniş şəkildə istifadə olunur, milyonlarla veb saytın qarşısında yerləşərək şəffaf şəkildə sürət və təhlükəsizlik əlavə edir.

Reverse Proxy Əslində Nə Edir

  • Yük balansı — sorğuları bir neçə backend server arasında paylayır
  • Keşləmə — tez-tez sorğulanan məzmunu daha sürətli təqdim edir
  • SSL termination — şifrələməni idarə edir ki, backend serverlər bunu etməli olmasın
  • Təhlükəsizlik — backend server təfərrüatlarını gizlədir və zərərli trafiki filtrləyir

Şirkətlər Reverse Proxy-ləri Niyə İstifadə Edir

Əlavə sürət və təhlükəsizlikdən başqa, reverse proxy backend arxitektura dəyişikliklərini sadələşdirir — onun arxasındakı serverlər əlavə edilə, silinə və ya yenidən qurula bilər, ziyarətçilər və ya onların brauzerləri heç bir dəyişiklik olduğunu bilməyə ehtiyac duymaz.

Tez-tez Verilən Suallar

Reverse proxy yük balanseri ilə eynidir?

Əlaqəli, lakin fərqlidir — reverse proxy bir neçə mümkün funksiyadan biri kimi yük balansını daxil edə bilən daha geniş bir konsepsiyadır.

Reverse proxy-lər veb sayt təhlükəsizliyini artırırmı?

Bəli — backend server təfərrüatlarını gizlədərək və trafiki filtrlərləyərək, reverse proxy mənalı bir qoruma təbəqəsi əlavə edir.

Reverse proxy-də 'SSL termination' nədir?

HTTPS trafikinin şifrələnməsini və deşifrəsini proxy səviyyəsində idarə etmək, beləliklə backend serverlərinin hər birinin sertifikatları fərdi olaraq idarə etməsinə ehtiyac qalmır.

Cloudflare reverse proxy-dir?

Bəli — Cloudflare-in əsas xidməti reverse proxy kimi funksiya göstərir, performans və təhlükəsizlik üstünlükləri əlavə etmək üçün veb saytların qarşısında yerləşir.

Reverse proxy məzmunu keşləyə bilərmi?

Bəli — tez-tez sorğulanan məzmunu proxy səviyyəsində keşləmək reverse proxy-lərin sayt sürətini artırmasının ümumi bir yoludur.

Kiçik veb saytların reverse proxy-yə ehtiyacı varmı?

Çox kiçik saytlar üçün həmişə lazım deyil, lakin bir çox hosting platformaları əlavə konfiqurasiya olmadan standart olaraq reverse proxy funksionallığını daxil edir.

Əsas Qeydlər

  • Reverse proxy ziyarətçilər və backend serverlər arasında yerləşir, sorğuları ötürür.
  • O, adətən yük balansı, keşləmə, SSL termination və təhlükəsizlik əlavə edir.
  • O, müştəriləri deyil, serverləri gizlədən forward proxy-nin əksidir.
  • Nginx və Cloudflare geniş istifadə olunan reverse proxy texnologiyalarıdır.
  • Reverse proxy ziyarətçilərə birbaşa təsir etmədən backend dəyişikliklərini sadələşdirir.
