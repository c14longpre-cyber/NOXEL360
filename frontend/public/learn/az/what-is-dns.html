Bir cümlə ilə: DNS (Domain Name System) internetin kataloq xidmətidir — o, noxel360.com kimi insanlar üçün oxunaqlı domen adlarını kompüterlərin bir-birini tapmaq üçün istifadə etdikləri rəqəmsal IP ünvanlarına çevirir.

DNS o qədər etibarlı şəkildə arxa planda işləyən sistemlərdən biridir ki, əksər insanlar bu barədə heç düşünmürlər — o sınana qədər və qəfildən mükəmməl işləyən veb sayt əlçatmaz olana qədər.

Telefon Kitabı Analogiyası

DNS-i köhnə telefon kitabı kimi düşünün. Siz biznesin adını bilirsiniz, telefon nömrəsini yox — DNS adı axtarır və əlaqə yaratmaq üçün lazım olan faktiki ünvanı qaytarır.

💡 Bilirdinizmi?

DNS bütün dünyada gündə trilyonlarla sorğunu idarə edir, lakin tipik DNS sorğusu cəmi bir neçə millisaniyə çəkir — tək göz qırpımından daha sürətli.

DNS Sorğusu Zamanı Nə Baş Verir

  1. Brauzerinizə domen adı yazırsınız.
  2. Cihazınız DNS serverindən IP ünvanını soruşur.
  3. DNS serveri düzgün ünvanla cavab verir.
  4. Brauzerin indi hansı serverlə əlaqə saxlamalı olduğunu bilir.

Ümumi DNS Qeyd Növləri

  • A qeydi — domeni birbaşa IP ünvanına yönəldir
  • CNAME qeydi — domeni başqa domen adına yönəldir
  • MX qeydi — e-poçtu düzgün poçt serverinə yönləndirir
  • TXT qeydi — mətn məlumatlarını saxlayır, tez-tez doğrulama üçün istifadə olunur

DNS Dəyişikliklərinin Niyə Vaxt Aldığı

DNS qeydləri interneti sürətli saxlamaq üçün bütün dünyada serverlər tərəfindən keşlənir — buna görə dəyişiklik hər yerdə dərhal qüvvəyə minmir. Yayılma adlanan bu gecikmə bir neçə dəqiqədən 48 saata qədər çəkə bilər.

Tez-tez Verilən Suallar

DNS dəyişiklikləri niyə işləməsi üçün vaxt alır?

Qeydlər bütün dünyada serverlər tərəfindən keşlənir. Dəyişiklik hər yerdə yayılması üçün bir neçə dəqiqədən 48 saata qədər vaxt ala bilər — buna yayılma deyilir.

CNAME qeydi nədir?

Bir domeni birbaşa IP ünvanına deyil, başqa domen adına yönəldən qeyd — hostinq platformalarına qoşularkən tez-tez istifadə olunur.

DNS problemləri işləyən veb saytı dayandıra bilərmi?

Bəli. Hətta mükəmməl işləyən server belə, DNS qeydi səhv konfiqurasiya edilmiş və ya vaxtı keçmiş olduqda əlçatmaz ola bilər.

A qeydi nədir?

Domeni birbaşa rəqəmsal IP ünvanına yönəldən DNS qeyd növü — ən əsas və ümumi qeyd növü.

Domen üçün DNS-i kim idarə edir?

Adətən domen qeydiyyatçısı və ya ayrıca DNS provayderi, qeydlərin əlavə edildiyi və ya redaktə edildiyi idarəetmə paneli vasitəsilə konfiqurasiya edilir.

Domen qeydiyyatçımdan fərqli DNS provayderi istifadə edə bilərəmmi?

Bəli — bir çox insan əlavə funksiyalar və performans üçün domenin ad serverlərini Cloudflare kimi ayrıca DNS provayderinə yönəldir.

MX qeydi nə üçün istifadə olunur?

O, internetə domeninizdəki ünvanlara göndərilən e-poçtu hansı poçt serverinin qəbul etməli olduğunu bildirir.

DNS veb hostinqlə eynidir?

Xeyr. DNS brauzerə serverinizi harada tapa biləcəyini bildirir; hostinq veb saytınızın faktiki fayllarının yerləşdiyi yerdir.

Əsas Qeydlər

  • DNS insanlar üçün oxunaqlı domen adlarını rəqəmsal IP ünvanlarına çevirir.
  • Tipik DNS sorğusu millisaniyələrdə tamamlanır, sürət üçün keşlənir.
  • Ümumi qeyd növlərinə A, CNAME, MX və TXT daxildir.
  • DNS dəyişiklikləri bütün dünyada yayılmaq üçün 48 saata qədər vaxt ala bilər.
  • DNS səhv konfigurasiyası başqa cür işləyən saytı əlçatmaz edə bilər.
