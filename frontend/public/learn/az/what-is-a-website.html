Bir cümlə ilə: Veb-sayt dünyanın hər hansı bir yerindəki serverdə saxlanılan və bir domen adına daxil olduqda brauzerinizin yükləyib göstərdiyi əlaqəli səhifələr toplusudur.

Veb-saytları adi hesab etmək asandır, lakin veb ünvanı yazmaq və səhifənin görünməsi arasında saniyənin bir hissəsində çox şey baş verir. Əsas hissələri başa düşmək hər bir digər veb konsepsiyasını daha sürətli yerli-yerinə salmağa kömək edir.

Veb-saytın əslində nədən təşkil olunduğu

  • Səhifələr — HTML ilə yazılmış fərdi sənədlər
  • Stilizasiya — səhifələrin necə göründüyünü idarə edən CSS
  • Davranış — elementləri interaktiv edən JavaScript
  • Aktivlər — şəkillər, şriftlər və digər istinad olunan fayllar
  • Server — daim onlayn olan və sorğu əsasında bütün bunları saxlayan və göndərən kompüter
💡 Bilirdinizmi?

1991-ci ildə Tim Berners-Lee tərəfindən dərc olunan ilk veb-sayt bu gün hələ də orijinal ünvanında onlayndır və müasir saytlara oxşamır — yalnız sadə mətn və keçidlər.

Veb-sayta daxil olduqda nə baş verir

  1. Domen adı yazırsınız və ya keçidə klikləyirsiniz.
  2. Brauzeriniz həmin domenin hansı serverə işarə etdiyini axtarır (DNS vasitəsilə).
  3. Brauzeriniz həmin serverdən səhifə sorğusu göndərir.
  4. Server səhifənin fayllarını geri göndərir.
  5. Brauzeriniz gördüyünüz hər şeyi birləşdirib göstərir.

Bütün bunlar adətən bir saniyədən çox az vaxtda baş verir — hətta planetin digər ucunda belə.

Veb-sayt vs Veb Tətbiq

Sərt texniki sərhəd yoxdur, amma faydalı bir qayda: veb-sayt daha çox məzmunu oxumaq haqqındadır — bloq, şirkət səhifəsi. Veb tətbiq brauzerdə işləyən interaktiv proqram təminatıdır — idarə paneli, kassa axını. Bir çox müasir məhsul hər ikisini birləşdirir.

Tez-tez verilən suallar

Veb-sayt ilə veb tətbiq arasında nə fərq var?

Ümumiyyətlə, veb-sayt daha çox məlumat xarakteri daşıyır, veb tətbiq isə brauzerdə işləyən interaktiv proqram təminatıdır — bir çox məhsul hər ikisini birləşdirir.

Veb-sayta sahib olmaq üçün domen adına malik olmaq lazımdırmı?

Xeyr — veb-sayt xam IP ünvanında və ya pulsuz subdomen üzərində işləyə bilər, lakin etibarlı görünməli hər hansı bir şey üçün fərdi domen standartdır.

Veb-sayt ilə veb səhifə eyni şeydirlərmi?

Xeyr. Veb səhifə tək bir səhifədir. Veb-sayt isə bir domen altında birlikdə yerləşən səhifələrin tam toplusudur.

Veb-saytın işləməsi üçün minimum nə lazımdır?

Minimum olaraq, bir HTML faylı və onu yerləşdirmək üçün server — CSS, JavaScript və əlavə səhifələr isteğe bağlı əlavələrdir.

Veb-sayt JavaScript olmadan işləyə bilərmi?

Bəli, bir çox veb-saytlar yalnız HTML və CSS ilə tam funksionaldır. JavaScript interaktivlik əlavə edir, lakin əsas məzmun üçün mütləq tələb olunmur.

Niyə bəzi veb-saytlar digərlərindən daha sürətli yüklənir?

Amillərə server yeri və sürəti, fayl ölçüləri, CDN istifadəsi və saytın kodunun nə qədər səmərəli yazılması daxildir.

Bloq veb-sayt hesab olunurmu?

Bəli — bloq sadəcə müntəzəm dərc olunan məqalələr ətrafında qurulmuş veb-saytdır, adətən arxasında xüsusi məzmun idarəetmə sistemi var.

Veb-sayta sahib olmaq üçün kod yazmağı bilmək lazımdırmı?

Mütləq deyil. Shopify, WordPress və Squarespace kimi veb-sayt qurucuları kod yazmadan qurmağa imkan verir.

Veb-saytı 'responsiv' edən nədir?

Tərtibatı müxtəlif ekran ölçülərinə uyğunlaşdıran CSS texnikaları, beləliklə eyni sayt telefonlarda, planşetlərdə və masaüstü kompüterlərdə yaxşı işləyir.

Tipik kiçik biznes veb-saytı neçə səhifəyə malikdir?

Tez-tez 5-10: ana səhifə, haqqında, xidmətlər, əlaqə və bir neçə dəstəkləyici səhifə, baxmayaraq ki, bu, biznes növündən asılı olaraq geniş dəyişir.

Əsas nəticələr

  • Veb-sayt serverdə saxlanılan və sorğu əsasında brauzerlərə çatdırılan əlaqəli səhifələr toplusudur.
  • Səhifələr, stilizasiya, davranış, aktivlər və server əsas tikinti blokları.
  • Sayta daxil olmaq DNS axtarışı, sorğu və cavab tetikləyir — hamısı bir saniyədən az müddətdə.
  • Veb-saytlar məlumat xarakterli olur; veb tətbiqlər interaktiv proqram təminatı olur.
  • Bu gün əsas veb-sayt qurmaq üçün kod yazmaq lazım deyil.
