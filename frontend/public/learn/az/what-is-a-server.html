Bir cümlə ilə: Server, veb saytın fayllarını saxlayan və ziyarətçilərə sorğu əsasında göndərən kimi digər kompüterlərə xidmət göstərən kompüterdir (və ya üzərində işləyən proqram təminatı).

Hər bir veb sayt, tətbiq və onlayn xidmət nəhayət bir yerdə serverdə işləyir — sorğu gələn kimi cavab verməyə hazır, həmişə açıq, həmişə qoşulu maşın.

Müştəri-Server Modeli

İnternetin demək olar ki, hamısı bu əsas nümunədə işləyir: müştəri (sizin brauzeriniz və ya tətbiqiniz) sorğu göndərir və server onu emal edir və cavabı göndərir — səhifələr, məlumatlar, fayllar, nə sorğu göndərilibsə.

💡 Bilirdinizmi?

Əsas bulud provayderləri hər biri yüz minlərlə serverə malik məlumat mərkəzləri işlədir, lakin veb sayt ziyarətçisinin baxımından bütün bu mürəkkəblik görünməzdir — sadəcə tək, sürətli veb sayt kimi görünür.

Ümumi Server Növləri

  • Veb serverləri — veb sayt fayllarını brauzerlərə təqdim edir
  • Verilənlər bazası serverləri — strukturlaşdırılmış məlumatları saxlayır və əldə edir
  • Tətbiq serverləri — tətbiqin arxasındakı faktiki biznes məntiqini işlədir
  • Fayl serverləri — şəbəkədə faylları saxlayır və paylaşır
  • Poçt serverləri — e-poçt göndərir və qəbul edir

Fiziki və Virtual Serverlər

Fiziki server real, xüsusi maşındır. Virtual server paylaşılan fiziki avadanlıqda ayrı kompüteri simulyasiya edən proqram təminatıdır — müasir bulud hesablamalarında dominant model, bir çox virtual serverlərin bir fiziki maşını səmərəli paylaşmasına imkan verir.

Tez-tez Verilən Suallar

Serverim olması üçün fiziki avadanlığa sahib olmaq lazımdırmı?

Xeyr — müasir müəssisələrin əksəriyyəti birbaşa fiziki maşınlara sahib olmaq əvəzinə bulud provayderlərindən virtual serverlər icarəyə götürür.

Server ilə kompüter arasında nə fərq var?

İstənilən kompüter server proqramı işlədirsə, texniki cəhətdən server kimi fəaliyyət göstərə bilər; termin adətən etibarlı şəkildə sorğulara cavab verməyə həsr olunmuş, tez-tez həmişə işləyən maşına aiddir.

Bir server bir neçə veb saytı yerləşdirə bilərmi?

Bəli — bu, xüsusən paylaşılan və ya virtual hostinqdə yayğındır, burada tək fiziki maşın bir çox ayrı veb saytları yerləşdirir.

Serverin 'sıradan çıxması' nə deməkdir?

Bu, serverin sorğulara cavab verməyi dayandırdığını bildirir, adətən qəza, həddindən artıq yüklənmə, şəbəkə problemi və ya təmir səbəbindən.

Virtual server fiziki serverdən daha az etibarlıdırmı?

Xas olaraq yox — müasir virtuallaşdırma texnologiyası yetkin və hətta ən böyük, ən tələbkar veb saytlar üçün belə istehsalda geniş istifadə olunur.

Server uptime nədir?

Serverin əslində əlçatan və sorğulara cavab verdiyi zaman faizi, Veb Əsasları sütununda əhatə olunan əsas etibarlılıq göstəricisidir.

Bütün veb saytların xüsusi serverə ehtiyacı varmı?

Xeyr — kiçik saytlar adətən digər saytlarla server resurslarını paylaşır (paylaşılan hosting), daha böyük və ya daha tələbkar saytlar isə xüsusi və ya bulud resurslarından istifadə edir.

Əsas Nəticələr

  • Server sorğuları emal edir və brauzerlər kimi müştərilərə cavab göndərir.
  • Veb, verilənlər bazası, tətbiq, fayl və poçt serverləri müxtəlif məqsədlərə xidmət edir.
  • Fiziki serverlər real maşınlardır; virtual serverlər fiziki avadanlığı səmərəli paylaşır.
  • Müasir müəssisələrin əksəriyyəti fiziki avadanlığa sahib olmaq əvəzinə bulud serverləri icarəyə götürür.
  • Müştəri-server modeli internetin necə işlədiyinin demək olar ki, hamısının əsasını təşkil edir.
