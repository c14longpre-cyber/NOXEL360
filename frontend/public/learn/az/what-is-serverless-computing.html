Bir cümlə ilə: Serverless computing tərtibatçılara heç bir serveri birbaşa idarə etmədən kod işlətməyə imkan verir — bulud provayderi avtomatik olaraq təminetmə, miqyaslandırma və infrastrukturu idarə edir, yalnız faktiki istifadəyə görə ödəniş tələb edir.

Adına baxmayaraq, serverless computing hələ də real serverlərdə işləyir — termin tərtibatçının heç vaxt onlar haqqında birbaşa idarə etməli və ya düşünməli olmaması deməkdir.

Adın Nə Üçün Bir Qədər Yanlış Anlaşıldığı

Serverlər hələ də arxa planda mövcuddur. "Serverless" xüsusi olaraq o deməkdir ki, tərtibatçı heç vaxt həmin serverləri birbaşa təmin etmir, konfiqurasiya etmir və ya idarə etmir — bulud provayderi bütün bunları avtomatik idarə edir.

💡 Bilirdinizmi?

Serverless funksiya heç kim əl ilə əlavə serverlər təmin etmədən bir neçə saniyə ərzində sıfırdan minlərlə eyni vaxtda icraatlara avtomatik olaraq miqyaslana bilər.

Serverless Computing Əslində Necə İşləyir

Kod kiçik, müstəqil funksiyalar kimi yerləşdirilir. Bulud provayderi yalnız tetikləndikdə həmin funksiyanı avtomatik işlədir, tələbə əsasən dərhal miqyaslandırır və tərtibatçı yalnız istifadə olunan faktiki hesablama vaxtına görə ödəyir.

Əsl Güzəştlər

Üstünlüklər: server idarəetməsi yoxdur, avtomatik miqyaslandırma, yalnız faktiki istifadəyə görə ödəniş. Çatışmazlıqlar: əsas mühitə daha az nəzarət, potensial "cold start" gecikmələri və çox yüksək həcmdə gözlənilməz şəkildə artması mümkün olan xərclər.

Tez-tez Verilən Suallar

Serverless computing heç bir serverin olmadığı deməkdirmi?

Xeyr — serverlər hələ də arxa planda kodu işlədir. 'Serverless' o deməkdir ki, tərtibatçı heç vaxt onları birbaşa təmin etməli və ya idarə etməli deyil.

Serverless computing ənənəvi hostingdən daha ucuzdurmu?

Çox vaxt dəyişkən və ya az trafikli iş yükləri üçün bəli, çünki siz daim işləyən server əvəzinə yalnız faktiki istifadəyə görə ödəyirsiniz.

Serverless computing-də 'cold start' nədir?

Serverless funksiya bu yaxınlarda işləməyəndə və yeni sorğunu icra etməzdən əvvəl başlatmalı olduqda baş verə biləcək qısa gecikmə.

Ümumi serverless platformalar hansılardır?

AWS Lambda, Google Cloud Functions və Vercel Functions bu gün ən geniş istifadə olunan serverless computing platformalarıdır.

Serverless computing hər növ tətbiq üçün yaxşıdırmı?

Xeyr — xüsusi, hadisə-əsaslı vəzifələr üçün yaxşı uyğundur, lakin daimi, proqnozlaşdırıla bilən performans və ya xüsusi mühitlərə ehtiyacı olan tətbiqlər üçün həmişə ideal deyil.

Serverless funksiyalar avtomatik olaraq miqyaslana bilərmi?

Bəli — bu serverless computing-in əsas üstünlüklərindən biridir, əl ilə müdaxilə olmadan sıfırdan yüksək tələbə qədər avtomatik miqyaslanır.

Serverless computing DevOps ehtiyacını tamamilə aradan qaldırırmı?

Xeyr — müəyyən infrastruktur idarəetmə vəzifələrini azaldır, lakin yerləşdirmə, monitorinq və kod keyfiyyəti praktikası hələ də vacibdir.

Əsas Nəticələr

  • Serverless computing tərtibatçının serverləri birbaşa idarə etmədən kodu işlədir.
  • Bulud provayderi avtomatik olaraq miqyaslandırma və infrastrukturu idarə edir.
  • Qiymətləndirmə adətən daimi işləyən server deyil, faktiki istifadəyə əsaslanır.
  • Cold start-lar və azaldılmış mühit nəzarəti real güzəştlərdir.
  • Xüsusilə hadisə-əsaslı və ya dəyişkən trafikli vəzifələr üçün uyğundur.
