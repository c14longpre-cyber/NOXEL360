Veb Əsasları Bələdçiləri

Hər veb saytın işlədiyi əsas tikinti blokları — domenlər, DNS, hostinq və hamısını təhlükəsiz saxlayan təhlükəsizlik təbəqəsi.

Veb Sayt Nədir?

Veb saytın əslində nə olduğu və serverdən ekranınıza necə çatdığı.

Domen Adı Nədir?

Domen adının əslində nə olduğu və veb hostinqdən necə fərqli olduğu.

DNS Nədir?

Domen adlarının kompüterlərin faktiki olaraq istifadə etdiyi ünvanlara necə çevrildiyini.

IP Ünvanı Nədir?

IP ünvanlarının nə olduğu, IPv4-ə qarşı IPv6 və onlaynda hər cihazın niyə birinə ehtiyacı var.

HTTP və HTTPS: Fərq Nədir?

Fərqin əslində nə olduğu və HTTPS-in bu gün hər veb sayt üçün niyə vacib olduğu.

SSL/TLS Nədir?

SSL və TLS-in əslində nə etdiyi və sertifikatların HTTPS kilid simvolunu necə gücləndirdiyi.

Veb Hostinq Nədir?

Veb hostinqin əslində nə olduğu və mövcud olan əsas növləri.

Bulud Hesablama Nədir?

Bulud hesablamanın əslində nəyi ifadə etdiyi və niyə fiziki serverə sahib olmağı əvəz etdiyi.

CDN Nədir?

Məzmun çatdırılma şəbəkələrinin veb saytların dünyanın hər yerində daha sürətli yüklənməsini necə təmin etdiyi.

Bant Genişliyi Nədir?

Bant genişliyinin nəyi ölçdüyü və sürətdən necə fərqləndiyi.

İşləmə Vaxtı Nədir?

İşləmə vaxtının nəyi ölçdüyü və 99.9%-in göründüyündən daha çox niyə vacib olduğu.
