UX Nədir? Sadə İzahat

Bir cümlə ilə: UX (İstifadəçi Təcrübəsi) bir məhsul və ya veb saytdan istifadə edərkən insanın yaşadığı ümumi təcrübədir — etmək istədiyi şeyi yerinə yetirməyin nə qədər asan, səmərəli və qane edici olduğu.

UX məhsul və dizayn söhbətlərində davamlı olaraq müzakirə olunur, çox vaxt vizual dizaynla qarışdırılır. Əslində isə bu, daha geniş bir şeyi əhatə edir: bir şeydən istifadənin bütün təcrübəsi, təkcə necə göründüyü deyil.

UX Sadəcə 'Şeyləri Gözəl Göstərmək' Deyil

Gözəl dizayn olunmuş ekran çaşqın, yavaş və ya insana məqsədinə çatmağa kömək etmirsə, yenə də dəhşətli UX-ə sahib ola bilər. UX fundamental olaraq bütün səyahətlə bağlıdır — qarşılıqlı əlaqədən əvvəl, zamanı və sonra.

💡 Bildinizmi?

"İstifadəçi təcrübəsi" termini 1990-cı illərdə Apple-da koqnitiv alim olan Don Norman tərəfindən məşhurlaşdırıldı, o, məhsulla bütün qarşılıqlı əlaqəni əhatə edən "istifadə qabiliyyəti"ndən daha geniş bir termin istəyirdi.

UX Əslində Nələri Əhatə Edir

  • İstifadə Qabiliyyəti — insanlar əslində istifadə etməyi başa düşə bilirlər?
  • Əlçatanlıq — hamı, o cümlədən əlilliyi olan insanlar da istifadə edə bilir?
  • Tapıla Bilmə — insanlar axtardıqlarını tapa bilirlər?
  • Etibarlılıq — etibarlı görünür?
  • Arzuolunan Olma — istifadəsi xoş hiss olunur, təkcə funksional deyil?

Niyə Yaxşı UX Biznes Üçün Vacibdir

Çaşdırıcı məhsullar hər addımda müştəriləri itirir — qeydiyyat zamanı, ödəniş mərhələsində, dəstək sorğularında. Yaxşı UX birbaşa bu sürtünməni azaldır və bu, real biznes göstəricilərində özünü göstərir: konversiya nisbəti, saxlanılma və dəstək xərcləri.

Tez-tez Verilən Suallar

UX və UI eyni şeydir?

Xeyr. UX bütün təcrübəni və bir şeydən istifadənin necə hiss olunduğunu əhatə edir. UI isə insanların qarşılıqlı əlaqədə olduğu xüsusi vizual interfeys — düymələr, rənglər, tərtibat — deməkdir.

Kiçik məhsul üçün xüsusi UX dizayneri lazımdır?

Əvvəlcə mütləq deyil, amma əsas UX prinsiplərini tətbiq etmək — aydın naviqasiya, sadə axınlar — komandanın ölçüsündən asılı olmayaraq hər bir məhsula fayda verir.

UX yalnız rəqəmsal məhsullar üçün aktualdır?

Xeyr — UX prinsipləri qismən fiziki məhsul dizaynından mənşə alır və istənilən qarşılıqlı əlaqəyə şamil olunur, baxmayaraq ki, bu gün ən çox proqram təminatında müzakirə olunur.

UX necə ölçülür?

Ümumi metodlara istifadə qabiliyyəti testləri, istifadəçi müsahibələri, tapşırıq tamamlanma nisbətləri və istifadəçilərin harada kənara çıxdığı və ya sıxıldığı yerlərinin təhlili daxildir.

UX və müştəri təcrübəsi (CX) arasında fərq nədir?

UX adətən xüsusi olaraq məhsul qarşılıqlı əlaqələrinə fokuslanır; CX daha genişdir və marketinq, satış və dəstək boyunca bütün müştəri münasibətlərini əhatə edir.

İstifadəçi araşdırması olmadan yaxşı UX mövcud ola bilər?

Bu daha çətindir — istifadəçilərin nəyə ehtiyacı olduğu barədə fərziyyələr çox vaxt yanlışdır; əsl istifadəçi araşdırması və testi adətən heç kəsin gözləmədiyi problemləri üzə çıxarır.

UX dizaynı bəzən biznes məqsədləri ilə ziddiyyət təşkil edirmi?

Bəzən — aqressiv monetizasiya və ya məlumat toplama UX-ə zərər verə bilər. Ən yaxşı nəticələr adətən həqiqi istifadəçi ehtiyacları ilə biznes davamlılığı arasında tarazlığı təmin edir.

Əsas Fikirlər

  • UX bir məhsuldan istifadənin bütün təcrübəsini əhatə edir, təkcə vizual görünüşü deyil.
  • İstifadə qabiliyyəti, əlçatanlıq, tapıla bilmə, etibarlılıq və arzuolunan olma hamısı UX-ə aiddir.
  • Yaxşı UX birbaşa konversiyaya, saxlanılmaya və dəstək xərclərinə təsir edir.
  • UX və UI əlaqəlidir, lakin fərqlidir — UX bütün təcrübədir; UI vizual interfeydir.
  • Əsl istifadəçi araşdırması adətən fərziyyələrin qaçıracağı sürtünmə nöqtələrini üzə çıxarır.
