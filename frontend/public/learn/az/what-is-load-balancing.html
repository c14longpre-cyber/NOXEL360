Bir cümlə ilə: Yük balanslaşdırması daxil olan trafikin birdən çox server arasında paylaşdırılmasıdır ki, heç bir server həddindən artıq yüklənməsin, digərləri isə boş qalmasın, veb saytı yüksək tələbat altında belə sürətli və əlçatan saxlasın.

Populyar veb sayt hər hansı tək serverin etibarlı şəkildə idarə edə biləcəyindən çox daha çox trafik qəbul edə bilər. Yük balanslaşdırması bunu həll edir, həmin trafikin birlikdə işləyən bir neçə server arasında paylaşdırılması ilə.

Yük Balanslaşdırması Əslində Necə İşləyir

Yük balanslaşdırıcısı serverlər qrupunun qabağında dayanır, əvvəlcə bütün daxil olan trafikin qəbul edir. Sonra hər bir sorğunu onu idarə etməyə ən uyğun vəziyyətdə olan serverə paylayır — tez-tez cari yükə və ya sadə növbəyə əsaslanaraq.

💡 Bilirdinizmi?

Yük balanslaşdırıcıları serverin cavab verməyi dayandırdığını aşkarlaya və saniyələr içində ona trafik göndərməyi avtomatik dayandıra bilər — ziyarətçilər uğursuzluğu heç vaxt hiss etmirlər, çünki trafik sadəcə sağlam serverlərə yönləndirilir.

O Həmçinin Sürəti Deyil, Etibarlılığı Artırır

Əgər hovuzdakı serverlədən biri uğursuz olarsa, yük balanslaşdırıcısı avtomatik olaraq ona trafik göndərməyi dayandırır və qalan sağlam serverlərə yönləndirir — ziyarətçilər heç bir fasilə yaşamırlar, çünki uğursuzluq şəffaf şəkildə idarə olunur.

Ümumi Yük Balanslaşdırması Metodları

  • Round robin — sorğuların serverlər arasında bərabər dövr edilməsi
  • Ən az əlaqələr — trafikin ən az aktiv sorğusu olan serverə göndərilməsi
  • Coğrafi marşrutlaşdırma — trafikin ən yaxın server yerləşməsinə yönləndirilməsi

Tez-Tez Verilən Suallar

Hər veb sayta yük balanslaşdırması lazımdırmı?

Xeyr — orta trafiki olan kiçik saytlar adətən tək serverdə yaxşı işləyir; yük balanslaşdırması trafik və ya etibarlılıq tələbləri artdıqda dəyərli olur.

Yük balanslaşdırıcısının arxasında server uğursuz olarsa nə baş verir?

Yük balanslaşdırıcısı uğursuzluğu aşkarlayır və ona trafik göndərməyi dayandırır, sorğuları qalan sağlam serverlərə avtomatik yönləndirir.

Yük balanslaşdırması CDN ilə eyni şeydirmi?

Xeyr, baxmayaraq ki, əlaqəlidir — CDN keşlənmiş məzmunu coğrafi olaraq paylayır; yük balanslaşdırması canlı trafikin aktiv serverlər hovuzu arasında paylaşdırılmasıdır.

'Round robin' yük balanslaşdırması nədir?

Mövcud serverlər arasında bərabər dövr edən sadə üsul, hər yeni sorğunu ardıcıllıqla növbəti serverə göndərir.

Yük balanslaşdırması veb sayt sürətini artıra bilərmi?

Bəli — heç bir serverin həddindən artıq yüklənməsinin qarşısını almaqla, sorğular bir həddindən artıq yüklənmiş maşında olduğundan daha sürətli işlənir.

Müasir bulud platformaları yük balanslaşdırmasını avtomatik daxil edirmi?

Çoxu bunu edir, platformaya defolt olaraq daxil edilib, tipik istifadə halları üçün əl ilə konfiqurasiya ehtiyacını aradan qaldırır.

Əsas Nəticələr

  • Yük balanslaşdırması həddindən artıq yükün qarşısını almaq üçün trafikin birdən çox server arasında paylaşdırılmasıdır.
  • O, server hovuzunun qabağında dayanır, hər bir sorğunu müvafiq şəkildə yönləndirir.
  • Uğursuz serverlər avtomatik aşkarlanır və növbədən çıxarılır.
  • Round robin və ən az əlaqələr ümumi paylama metodlarıdır.
  • Yük balanslaşdırması real trafik altında həm sürəti, həm də etibarlılığı artırır.
