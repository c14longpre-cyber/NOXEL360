Bir cümlə ilə: Konteynerlər tətbiqi işləmək üçün lazım olan hər şeylə birlikdə — kod, kitabxanalar, parametrlər — paketləyir ki, hansı kompüter və ya serverdə yerləşdirildiyindən asılı olmayaraq ardıcıl davransın.

Proqram təminatında ən adi məyusluqlardan biri həmişə "mənim maşınımda işləyir" olub — kodun müxtəlif mühitlərdə fərqli davranması. Konteynerləri xüsusi olaraq bunu həll etmək üçün yaradıblar.

Konteynerlərlərin Həll Etdiyi Problem

Tətbiq adətən spesifik proqram versiyalarından, kitabxanalardan və konfiqurasiyalardan asılıdır. Konteynersiz, developer-in maşını ilə produksiya serveri arasında fərqlər yaxşı işləyən kodun qəfildən pozulmasına səbəb ola bilər.

💡 Bilirdinizmi?

2013-cü ildən etibarən konteynerlərləri əsas axına çıxaran texnologiya olan Docker, adını və daşıma konteyneri ikonunu birbaşa qlobal yük daşımasında inqilab edən standartlaşdırılmış yük konteynerlərdən götürüb.

Konteynerlərlərin Əslində Necə İşləməsi

Konteynerlər tətbiqi dəqiq asılılıqları ilə birlikdə tək, daşına bilən paketə birləşdirir. Bu paket developer-in noutbukunda, test serverində və ya produksiyada olduğundan asılı olmayaraq eyni şəkildə işləyir — konteynerdaxili mühit ardıcıl qalır.

Konteynerler və Virtual Maşınlar

Virtual maşın öz əməliyyat sistemi də daxil olmaqla bütöv ayrıca kompüteri simulyasiya edir — daha ağır və başlamaq üçün daha yavaş. Konteynerlər isə host sistemin nüvəsini daha səmərəli paylaşır, bu da onu daha yüngül və başlamaq üçün daha sürətli edir.

Tez-tez Verilən Suallar

Docker konteynerlər ilə eynidir?

Docker konteynerlər yaratmaq və işlətmək üçün ən məşhur platformadır, lakin daha geniş konteynerlər konsepsiyasının bir tətbiqi olub, yeganə deyil.

Konteynerler virtual maşınlar ilə eynidir?

Xeyr — konteynerler daha yüngüldür, virtual maşınlar kimi ayrıca tam əməliyyat sistemini simulyasiya etmək əvəzinə host sistemin nüvəsini paylaşırlar.

Müasir hostinq platformalarından istifadə etmək üçün konteynerlərləri başa düşməliyəm?

Mütləq deyil — bir çox platformalar konteynerlərləşdirməni arxa planda həll edir, baxmayaraq ki, konsepti başa düşmək problem həlli və ya miqyaslama zamanı kömək edir.

Konteynerler niyə virtual maşınlardan daha sürətli başlayır?

Çünki onlar ayrı tam əməliyyat sistemini yükləməyə ehtiyac duymur — host sistemin nüvəsini paylaşaraq müqayisədə demək olar ki, dərhal başlayırlar.

Bir serverdə bir neçə konteynerlər işləyə bilər?

Bəli — bu adi və səmərəlidir, çünki konteynerler eyni fiziki və ya virtual serverdə eyni zamanda çoxlu sayda işləmək üçün kifayət qədər yüngüldür.

Kubernetes-in konteynerlər ilə əlaqəsi nədir?

Kubernetes bir neçə serverdə birlikdə işləyən çoxlu konteynerlərləri idarə edir və orkestrləşdirir, miqyaslamı və bərpanı avtomatik həll edir.

Konteynerlər yalnız böyük şirkətlər tərəfindən istifadə olunur?

Xeyr — konteynerlərdən hər ölçüdə komandalar və layihələr geniş istifadə edir, çünki ardıcıllıq faydası miqyasdan asılı olmayaraq tətbiq olunur.

Əsas Çıxarışlar

  • Konteynerlər tətbiqi ardıcıl işləmək üçün lazım olan hər şeylə birlikdə paketləyir.
  • Konteynerləri klassik "mənim maşınımda işləyir" problemini həll edir.
  • Docker konteynerlər yaratmaq və işlətmək üçün ən geniş istifadə olunan platformadır.
  • Konteynerler virtual maşınlardan daha yüngül və sürətlidir, host-un nüvəsini paylaşırlar.
  • Əsas fayda development və produksiya arasında ardıcıllıqdır.
