Адным сказам: IP-адрас — гэта унікальны лікавы ідэнтыфікатар, прызначаны кожнай прыладзе, падключанай да сеткі, каб дадзеныя ведалі дакладна, куды ісці.

Кожная прылада, падключаная да інтэрнэту — ваш тэлефон, ноўтбук і кожны сервер, які размяшчае кожны вэб-сайт — мае IP-адрас. Гэта сапраўдны пункт прызначэння, у які DNS пераўтварае даменнае імя.

Як выглядае IP-адрас

Тыповы адрас IPv4 выглядае як 192.168.1.1 — чатыры лікі, падзеленыя кропкамі, кожны ад 0 да 255. Гэта дазваляе прыкладна 4,3 мільярда унікальных адрасоў.

💡 Ці ведаеце вы?

IPv6 падтрымлівае прыкладна 340 ундэцыльёнаў унікальных адрасоў — дастаткова, каб прызначыць унікальны адрас кожнай пясчынцы на Зямлі шмат разоў.

IPv4 супраць IPv6

Калі колькасць прылад, падключаных да інтэрнэту, узрасла, свет пачаў выпраўляцца з адрасоў IPv4. IPv6 быў створаны для вырашэння гэтай праблемы, выкарыстоўваючы значна больш доўгі фармат, які дазваляе значна большую колькасць адрасоў. Абодва працуюць бок аб бок сёння.

Публічныя супраць прыватных IP-адрасоў

Прылады ў вашай хатняй сетцы кожная атрымлівае прыватны IP-адрас, бачны толькі ўнутры вашай сеткі. Уся ваша сетка выкарыстоўвае адзін публічны IP, прызначаны вашым інтэрнэт-правайдарам, які бачыць астатняя частка інтэрнэту.

Частыя пытанні

Ці раскрывае мой IP-адрас дакладнае месцазнаходжанне?

Звычайна агульны рэгіён, звязаны з вашым правайдарам, а не дакладны адрас. Дакладнасць значна адрозніваецца ў залежнасці ад правайдара і месцазнаходжання.

Чаму мы выпраўляемся з адрасоў IPv4?

IPv4 дазваляе ~4,3 мільярда унікальных адрасоў — занадта мала для сённяшняй колькасці падключаных прылад, таму быў створаны IPv6.

Ці мае кожны вэб-сайт свой уласны IP-адрас?

Часта некалькі вэб-сайтаў дзеляць адзін IP на адным серверы, адрозніваючыся па даменным імені — гэта не ўплывае на вопыт наведвальнікаў.

Ці можа мой IP-адрас змяняцца з часам?

Так, асабліва для хатніх інтэрнэт-злучэнняў, дзе правайдары часта прызначаюць дынамічныя IP, якія перыядычна змяняюцца.

Што такое статычны IP-адрас?

IP-адрас, які застаецца фіксаваным, а не змяняецца, часта выкарыстоўваецца для сервераў, якім патрэбен стабільны, прадказальны адрас.

Ці бяспечна дзяліцца маім IP-адрасам з кімсьці?

Звычайна нізкі рызыка сам па сабе, хоць ён можа раскрыць агульнае месцазнаходжанне і, у спалучэнні з іншымі дадзенымі, спрыяць адсочванню.

Ці могуць дзве прылады мець аднолькавы IP-адрас?

Не ў адной сетцы адначасова — гэта выклікала б канфлікт. Прыватныя IP могуць паўтарацца ў розных, асобных сетках.

Ключавыя высновы

  • Кожная прылада, падключаная да інтэрнэту, мае унікальны IP-адрас.
  • Адрасы IPv4 выглядаюць як 192.168.1.1; IPv6 выкарыстоўвае больш доўгі фармат для значна большай колькасці адрасоў.
  • Прыватныя IP прымяняюцца ў межах хатняй сеткі; публічны IP прадстаўляе ўсю сетку ў інтэрнэце.
  • DNS існуе менавіта для пераўтварэння зручных даменных імёнаў у гэтыя лікавыя адрасы.
  • IP-адрасы маюць значэнне непасрэдна пры наладцы DNS або правілаў брандмаўэра.
