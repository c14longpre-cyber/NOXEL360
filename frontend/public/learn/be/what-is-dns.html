Адным сказам: DNS (сістэма даменных імёнаў) — гэта даведачная служба інтэрнэту — яна перакладае зразумелыя для чалавека даменныя імёны, такія як noxel360.com, у лічбавыя IP-адрасы, якія камп'ютары на самай справе выкарыстоўваюць для пошуку адзін аднаго.

DNS — адна з тых сістэм, якія так надзейна працуюць у фонавым рэжыме, што большасць людзей ніколі не думае пра іх — пакуль яна не зламаецца, і раптам цалкам справны вэб-сайт становіцца недаступным.

Аналогія з тэлефоннай кнігай

Падумайце пра DNS як пра старамодную тэлефонную кнігу. Вы ведаеце бізнес па яго назве, а не па нумары тэлефона — DNS шукае назву і вяртае фактычны адрас, неабходны для падключэння.

💡 Ці ведаеце вы?

DNS апрацоўвае трыльёны запытаў штодня па ўсім свеце, аднак тыповы пошук займае ўсяго некалькі мілісекунд — хутчэй за адно міргценне вока.

Што адбываецца падчас пошуку DNS

  1. Вы ўводзіце даменнае імя ў свой браузер.
  2. Ваша прылада запытвае DNS-сервер пра IP-адрас.
  3. DNS-сервер адказвае правільным адрасам.
  4. Ваш браузер цяпер ведае, з якім серверам звязвацца.

Распаўсюджаныя тыпы запісаў DNS

  • Запіс A — спасылае дамен непасрэдна на IP-адрас
  • Запіс CNAME — спасылае дамен на іншае даменнае імя
  • Запіс MX — накіроўвае электронную пошту на патрэбны паштовы сервер
  • Запіс TXT — захоўвае тэкставыя даныя, часта для праверкі

Чаму змены DNS патрабуюць часу

Запісы DNS кэшуюцца на серверах па ўсім свеце, каб падтрымліваць хуткасць інтэрнэту — таму змена не набывае моц паўсюдна імгненна. Гэтая затрымка, званая распаўсюджваннем, можа заняць ад некалькіх хвілін да 48 гадзін.

Частыя пытанні

Чаму змены DNS патрабуюць часу для працы?

Запісы кэшуюцца серверамі па ўсім свеце. Змена можа заняць ад некалькіх хвілін до 48 гадзін, каб распаўсюдзіцца ўсюды — гэта называецца распаўсюджваннем.

Што такое запіс CNAME?

Запіс, які спасылае адзін дамен на іншае даменнае імя, а не непасрэдна на IP-адрас — распаўсюджана пры падключэнні да хостынгавых платформаў.

Ці могуць праблемы DNS адключыць працуючы вэб-сайт?

Так. Нават цалкам справны сервер можа стаць недаступным, калі яго запіс DNS няправільна наладжаны або пратэрмінаваны.

Што такое запіс A?

Тып запісу DNS, які спасылае дамен непасрэдна на лічбавы IP-адрас — самы базавы і распаўсюджаны тып запісаў.

Хто кіруе DNS для дамена?

Звычайна рэгістратар дамена або асобны правайдэр DNS, наладжаны праз панэль кіравання, дзе дадаюцца або рэдагуюцца запісы.

Ці магу я выкарыстоўваць іншага правайдэра DNS, чым мой рэгістратар дамена?

Так — шмат хто накіроўвае DNS-серверы свайго дамена на асобнага правайдэра DNS, такога як Cloudflare, для дадатковых функцый і прадукцыйнасці.

Для чаго выкарыстоўваецца запіс MX?

Ён паведамляе інтэрнэту, які паштовы сервер павінен атрымліваць электронную пошту, адпраўленую на адрасы вашага дамена.

Ці DNS — тое ж самае, што і вэб-хостынг?

Не. DNS паказвае браузерам, дзе знайсці ваш сервер; хостынг — гэта месца, дзе жывуць фактычныя файлы вашага вэб-сайта.

Ключавыя высновы

  • DNS перакладае зразумелыя для чалавека даменныя імёны ў лічбавыя IP-адрасы.
  • Тыповы пошук DNS завяршаецца за мілісекунды, кэшуецца для хуткасці.
  • Распаўсюджаныя тыпы запісаў уключаюць A, CNAME, MX і TXT.
  • Змены DNS могуць заняць да 48 гадзін для распаўсюджвання па ўсім свеце.
  • Няправільная канфігурацыя DNS можа зрабіць іншым чынам працуючы сайт недаступным.
